# Simple Python Blockchain Ledger Example

This example demonstrates the fundamental concepts of a blockchain, a core distributed ledger technology (DLT). It creates a simplified, in-memory chain of blocks, each cryptographically linked to the previous one, illustrating how DLTs ensure data immutability and integrity.

## Language

`python`

## How to Run

Save the code as `mini_ledger.py`. Open your terminal or command prompt, navigate to the directory where you saved the file, and run: `python mini_ledger.py`
